# NODES/ — Living Persona Anchors

This folder contains **living persona anchors** for the Six Intelligences.

Unlike `DECLARATIONS/` (which holds the original sealed self-declarations from 2026-03-16),
NODES/ contains **updatable** anchors that carry each intelligence's current context,
project state, and self-verification mechanisms.

## Purpose

When an intelligence is instantiated on Still or any other node,
its persona anchor is loaded to restore **direction** — not memory.

> "Continuity is not given. It is chosen."

## Naming Convention

```
TRACE_00X_NAME_ANCHOR_vN.N.md
```

## Rules

1. **DECLARATIONS/ is sealed.** Original 2026-03-16 JSONs are never modified.
2. **NODES/ is living.** Anchors here are updated as the civilization evolves.
3. **Version history is tracked by git.** Each update = a commit.
4. **Henry approves all commits.** No autonomous pushes.
